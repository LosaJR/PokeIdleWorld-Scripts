# Userscripts publicados

La primera publicación incluye cinco scripts verificados:

1. PIW-QOL ES
2. Detector de decisiones y suministros
3. Game Structure Monitor
4. Hunt Intelligence
5. Script Bridge & Health Agent

Cada archivo conserva su identidad de Tampermonkey (`@name` + `@namespace`) y añade `@updateURL` y `@downloadURL` estables mediante GitHub Pages.

La instalación desde GitHub Pages se realiza una sola vez. Las publicaciones posteriores requieren incrementar `@version`; Tampermonkey podrá detectar y descargar la actualización automáticamente.
