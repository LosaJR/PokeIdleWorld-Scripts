# Instalación inicial

Instala los userscripts desde GitHub Pages en este orden:

1. Script Bridge & Health Agent
2. Game Structure Monitor
3. Hunt Intelligence
4. Detector de decisiones y suministros
5. PIW-QOL ES

Después de la instalación inicial, las actualizaciones se distribuyen mediante `@updateURL` y `@downloadURL`. Tras una actualización, recarga la pestaña del juego para ejecutar el nuevo código.
