# Mantenimiento

1. Modifica el archivo correspondiente en `src/`.
2. Incrementa `@version`.
3. Conserva `@name`, `@namespace`, `@updateURL` y `@downloadURL`.
4. Abre un pull request y espera a que pase **Validar userscripts**.
5. Mezcla el cambio en `main`; el workflow de publicación actualizará `dist/`, el respaldo y GitHub Pages.
